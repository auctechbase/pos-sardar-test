# POS Sardar — test version

A test copy of the POS Sardar till for Windows. It uses a **test** shop with a copy of the catalogue: nothing you do here touches the real shop.

## Install

1. **[Download POS-Test-Setup.exe](https://github.com/auctechbase/pos-sardar-test/releases/latest/download/POS-Test-Setup.exe)** (about 140 MB).
2. Open the downloaded file. It installs and starts by itself; there is nothing to set up.
3. If Windows shows *"Windows protected your PC"*: click **More info**, then **Run anyway**. (The app is not signed with a paid certificate, so Windows asks once.)
4. Log in with:
   - Email: `test@sardar.local`
   - Password: `test1234`

Works on Windows 10 and 11. Printing is switched off in this test version. It needs the internet; if the connection drops, the till keeps selling and sends the sales when it is back.

## Remove

Windows Settings → Apps → **POS Test** → Uninstall.
